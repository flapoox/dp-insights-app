DP Insights – Privacy Policy

Last updated: 27 September 2026

DP Insights is a private reporting tool run by Digital Poonam (Raipur, Chhattisgarh, India) for its own social media and YouTube accounts. It is not offered to the public.

What we access

When an account owner connects a YouTube channel, DP Insights asks Google for read-only access (youtube.readonly and yt-analytics.readonly). It reads channel statistics, video details and YouTube Analytics reports such as views, watch time, subscribers and traffic sources.

How we use it

The data is used only to show performance charts and suggestions to the account owner in the DP Insights dashboard. It is never sold, shared with third parties or used for advertising. DP Insights cannot upload, edit or delete anything on YouTube.

Where it is stored

Report data is stored in the owner's private Google Sheet. Sign-in keys are stored privately inside the owner's Google Apps Script project and are not shown in the Sheet.

Removing access

You can remove access at any time from myaccount.google.com/permissions, or ask us to delete your data by writing to poo2181@gmail.com. DP Insights' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
